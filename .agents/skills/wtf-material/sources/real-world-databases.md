# 现实材料数据库

## 信源信息

| 数据库 | URL | Scope | 注意 |
| --- | --- | --- | --- |
| Mindat | https://www.mindat.org/ | 矿物种、IMA 编号、化学式、产地、命名 | 对爬虫 403，用 browser use |
| ATHENA | https://athena.unige.ch/minfich | 矿物 IMA 编号、化学式、晶系 | 轻量，可替代 Mindat |
| NIMRF | http://www.nimrf.net.cn/ | 中文矿物名、英文名、化学式、产状 | 适合规范中文名 |
| PubChem | https://pubchem.ncbi.nlm.nih.gov/ | 化合物、同义词、标准化学式 | 化合物为主 |
| Kew POWO | https://powo.science.kew.org/ | 植物/树种学名、俗名、分布 | 植物学权威库 |
| Geology.com | https://geology.com/ | 岩石/宝石科普、宝石变种 | 科普站，非学术 |
| JOGG | https://jogg.cug.edu.cn/ | 中文宝石学论文库 | 期刊库，具体论文看单篇 |

## 涵盖内容

- 矿物/矿物种：IMA 编号、化学式、晶系、产地、命名（Mindat、ATHENA、NIMRF）。
- 化合物：标准化学式、同义词、安全信息（PubChem）。
- 植物/树种：学名、俗名、分布（Kew POWO）。
- 岩石/宝石科普：岩性、宝石变种、通俗解释（Geology.com）。
- 中文宝石学论文库：玉石/宝石矿物组成（JOGG）。

## 注意事项

- 只收包含多个条目的数据库/期刊库；单篇论文、单篇新闻、单条矿物纪事不单独成文件，引用保留在材料条目的证据链接中。
- Mindat 对爬虫 403，用 browser use；ATHENA 轻量，可替代 Mindat 核对 IMA 编号。
- NIMRF 适合规范中文矿物名；PubChem 适合化合物；POWO 适合树种学名。
- Geology.com 是科普站，不是学术来源；JOGG 是期刊库，具体论文仍需看单篇。
- 引用具体条目页，不引用首页。
