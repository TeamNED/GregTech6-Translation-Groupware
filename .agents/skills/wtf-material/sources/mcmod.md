# MC百科

## 信源信息

- 地址：https://www.mcmod.cn
- GT6 条目：https://www.mcmod.cn/class/455.html
- GT6 非官方版：https://www.mcmod.cn/class/2281.html
- GT6CE：https://www.mcmod.cn/class/32292.html
- 搜索：站内搜索支持中英文 mod 名；也可以用 `site:mcmod.cn "<关键词>"`。

## 涵盖内容

- 中文 mod 条目：简介、物品/方块/材料列表、合成表、教程、汉化链接。
- 整合包条目：包含的 mod、魔改说明、任务线。
- 评论区/教程区有玩家常用译名和俗称。

## 注意事项

- 条目由玩家编辑，可能过时；注意页面标注的 mod 版本。
- 物品页的“材料”通常指合成材料，不一定等于 GregTech 的材料（Material）概念。
- 评论和教程是玩家观点，不是官方设定；只能作为“社区用法”的证据。
- 汉化下载链接可能指向旧版本，优先用 GitHub 仓库。
- 引用条目 URL，不要复制大段正文。
