# GTNH 百科

## 信源信息

- 中文：https://gtnh.huijiwiki.com
- 英文：https://wiki.gtnewhorizons.com
- 中文站内搜索：页面右上角搜索框；英文站用 MediaWiki 搜索。

## 涵盖内容

- GTNH 整合包（以 GT5U 为核心）的材料、机器、多方块、任务线、工艺流程。
- 材料页通常给出中文名、英文名、来源和用途。
- 英文站更完整，中文站更贴近中文社区术语。

## 注意事项

- GTNH 是 GT5U 体系，不是 GT6；材料名和配方可能不同，不能直接套用。
- 中文站可能有机器翻译或旧译名；重要结论回到英文站或代码确认。
- 页面常标注适用版本（如 2.8.x），注意时效。
- 对爬虫可能返回 403，用 browser use。
- 引用具体页面，不引用首页。
