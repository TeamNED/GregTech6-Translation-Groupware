# FTB Wiki

## 信源信息

- 地址：https://ftb.fandom.com （原 ftbwiki.org / Gamepedia 的 Feed The Beast Wiki）
- 搜索：站内搜索，或 `site:ftb.fandom.com "<关键词>"`。
- GT6 条目：https://ftb.fandom.com/wiki/GregTech_6

## 涵盖内容

- FTB 整合包、GregTech 各版本（GT5、GT5U、GT6）的机器、材料、物品、教程。
- 材料分类页和导航模板，适合查“这个材料属于哪个版本/哪个 mod”。

## 注意事项

- GT6 页面更新不勤，可能停留在早期版本；以 GitHub 代码和 changelog 为准。
- GT5/GT5U 内容远多于 GT6，搜索时注意页面标题里的版本号。
- 材料名可能用旧译名或英文直译。
- 对爬虫返回 403，用 browser use 或 WebFetch。
- 社区 Wiki，不是官方文档。
