# Wikipedia（中文 / 英文）

## 信源信息

- 英文：https://en.wikipedia.org
- 中文：https://zh.wikipedia.org
- 中文大陆用词：条目页右上角的用词转换，或 URL 加 `?variant=zh-cn`。
- 跨语言链接：左侧“其他语言”可从中/英条目互跳。

## 涵盖内容

- 现实元素、同位素、化合物、合金、矿物、宝石、材料科学。
- 作品条目（小说、影视、游戏）中的虚构物质，通常在“Setting”“Items”等段落。
- 人物、地名、神话传说中的物质名（如 mithril、adamant、orichalcum）。

## 注意事项

- 中文维基的条目名可能是繁体或地区词，和大陆常用译名不同；先看条目内的用词转换标签。
- 元素用 IUPAC 英文名；矿物用 IMA 矿物名；宝石名可能是商业名，三者不一定一致。
- 虚构材料在 Wikipedia 往往只有一句话，真正资料在作品 Wiki（Fandom/huijiwiki）。
- Wikipedia 不是一手来源。引用时给条目链接即可，不要把维基当“官方设定”。
- 注意同名不同物：`Adamant`/`Adamantine` 是古代传说中的物质，不等同于现实合金；`Tritanium` 是 Star Trek 的虚构材料。
- 现实材料查不到时，试试学名、IUPAC 名、矿物英文名，而不是 mod 里的名字。
